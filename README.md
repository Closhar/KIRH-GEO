# KIRH GEO

Платформа добровольного обмена геопозицией. Первый рынок — Россия; первый сценарий — группы по приглашению с отдельным режимом передачи своей позиции.

Статус: проектирование. Здесь пока нет работающих приложений или production-конфигурации.

## План

[Архитектура, схема данных и этапы реализации](.ai-factory/plans/platform-foundation.md).

Стек: React Native + TypeScript, Laravel API, PostgreSQL + PostGIS, Redis, WebSocket и push. Админка планируется внутри Laravel. Облачный PostgreSQL Beget рассматривается при подтверждении PostGIS и условий восстановления.

## Структура

- `apps/api` — API и админка.
- `apps/mobile` — приложение Android/iOS.
- `apps/share-web` — просмотр временного доступа.
- `packages/contracts` — будущие OpenAPI и генерируемый API-клиент.
- `infra` — будущая инфраструктура и процедуры развёртывания.
- `docs` — будущие спецификации и эксплуатационные инструкции.

Пустые каталоги зафиксированы через `.gitkeep`; зависимости и каркасы приложений появятся на соответствующих этапах плана.

## Разработка

Ветка `main` содержит проверенные контрольные точки. Функциональные изменения выполняются в отдельных ветках с проверкой diff и относящимися к изменению тестами. CI добавляется вместе с рабочим backend, чтобы проверки запускали реальные инструменты проекта.

Секреты, приватные ключи, резервные копии и реальные геоданные не добавляются в Git. SSH-настройки конкретного компьютера хранятся вне отслеживаемых файлов.
