# KIRH GEO

Russia-first voluntary group location sharing. One mobile app has viewer/group-management and sender modes, combinable per workspace. Invitation codes bootstrap separate user/device identities. Mutual visibility requires administrator permission plus subject consent. Central settings control GPS intervals and history retention within entitlement limits.

Implementation stack: Laravel 13 / PHP 8.3+, PostgreSQL + PostGIS, Redis, Laravel Reverb; React Native + TypeScript. Filament administration planned. Self-managed isolated database initially, cloud deferred. Plan: `plans/platform-foundation.md`. Tests mandatory, structured redacted logs, explicit status for external dependencies.
